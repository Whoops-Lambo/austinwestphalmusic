Connect your GitHub

Publishing is protected by your repository permissions. Use a fine-grained GitHub token with access to Whoops-Lambo/austinwestphalmusic and Contents: Read and write. Your token stays in memory and is cleared when you disconnect or close this page.

First-time setup
  1. Open GitHub token settings ↗ while signed in as the repository owner.
  2. Choose an expiration, select only austinwestphalmusic, and set repository Contents permission to Read and write.
  3. Generate the token and paste it below. Keep it private. Never add it to your repository or send it in chat.

The admin page is public; only an authorized token can publish. Content and uploaded PDFs become public on your website and in the repository. GitHub history keeps older versions.

Save draft keeps your edits on this browser. Publish sends all changes to GitHub; the live website updates after deployment. PDF uploads: up to 5 MB each.
